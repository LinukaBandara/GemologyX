# GemologyX 1,000+ Page Completion Programme

**Working branch:** `content/complete-and-expand-1000`  
**Starting point:** `seo/technical-foundation` at `74641d49d260aeb4807403c59250bd33719c6b8d`  
**Goal:** Build a useful, evidence-led gemology reference with 1,000+ concrete URLs over staged releases. This is a target, not a commitment to publish thin pages.

## Non-negotiable publishing standard

Every indexable page must have a distinct user purpose, original explanatory value, accurate title and description, a clear answer near the top, useful sections, meaningful internal links, suitable visual content, and sources/review notes where claims need verification. Do not create pages by swapping gemstone names into generic copy. Do not infer identity, treatment, quality, price or geographic origin from photographs. Do not publish unsupported market prices or legal requirements.

## Inventory baseline

The existing route inventory records 100 Sinhala learning files, 9 English learning files, data-driven gemstone/origin/glossary profiles, 6 tool routes and Sri Lankan mining content. The earlier architecture estimate was approximately 174 concrete URLs. Recount from the actual branch and data arrays before each release; source-file count is not the same as concrete URL count.

## Delivery phases

### Phase 1 — complete the existing experience
- Review all route files and dynamic data records.
- Identify thin, duplicated, incomplete or unsupported content.
- Improve pages in small reviewable batches while preserving existing URLs.
- Add relevant, rights-safe photographs, diagrams, comparison tables and maps where they materially improve understanding.
- Complete brand assets: primary mark, favicon/app icon, social preview and consistent header/footer use.
- Check mobile rendering, image loading, internal links, metadata, canonical/hreflang, sitemap and accessibility.

### Phase 2 — expand the reference datasets
- Expand gemstone profiles with distinct mineralogical, optical, treatment, care and sourcing information.
- Expand origins and Sri Lankan regional geology with careful sourcing.
- Expand the glossary with useful standalone definitions and cross-links.
- Add English coverage only where it is genuinely useful and independently written.

### Phase 3 — add genuinely new learning clusters
Prioritize Sri Lankan gem geology and mining, corundum/sapphire science, rough gemstones and lapidary, inclusions and identification limits, treatment disclosure, laboratory report literacy, and responsible buying/trade.

### Phase 4 — tools and structured learning
Add calculators and reference tools only where assumptions can be explained and outputs are useful. Add topic hubs, learning paths, comparison indexes and downloadable checklists where they improve navigation.

### Phase 5 — release QA and monitoring
For each batch: lint, production build, static route generation, duplicate slug checks, sitemap count, broken-link checks, image alt text/rights checks, mobile review and preview deployment review. Submit completed work through pull requests; do not merge or production-deploy without explicit owner approval.

## Visual asset policy

Prefer original diagrams and commissioned/appropriately licensed gem photographs. Record source, creator/licence and attribution requirements for external assets. Avoid hotlinking random images, watermarked stock, misleading AI specimen photography, or repeating one generic picture across unrelated pages. Use labelled educational illustrations where a real specimen photograph is unavailable.

## Progress tracking

Track each URL with: route, language, archetype, intent, status, content review, factual review, image/diagram status, internal-link status, metadata status, mobile QA, sources and reviewer date. Status values: Inventory, Draft, Content review, Visuals, QA, Ready for preview, Approved to publish.
